# Worth the Trip?

Chrome demo for comparing one exact headphone model across new, refurbished and local used listings. All prices, policies and seller reviews are fictional. The demo reads and follows links between bundled HTML pages. It uses deterministic rules and needs no accounts, external services or API keys.

1. Unzip the download.
2. Open chrome://extensions in Chrome and turn on Developer mode.
3. Select Load unpacked and choose the folder containing manifest.json.
4. Open a retailer product page and click Worth the Trip? from the extensions menu. The popup reads structured product metadata or recognises WH-1000XM5 in the main heading. It shows the detected product and retailer.
5. On an XM5 page, select Compare sample listings. On another tab, tick Use the bundled headphone example first. All comparison prices and policies come from the bundled example, including when product detection succeeds.

With £160 and 90 minutes the local pair wins at £133. Select Test local used before paying and run again. The local listing never confirms testing, so refurbished wins at £149. Open its warranty policy from the result card or expand Pages checked to see the source. To make new win, select None, set £210, 0 pickup minutes and a one-day deadline.

On the JBL UK Charge 6 product page, the extension recognises the product from its URL. Use the search links to look for new, refurbished and used listings, or type a product name if detection fails. The links open search results for you to review.
